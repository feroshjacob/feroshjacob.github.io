I'm starting a new series: CPU vs GPU Battle.

The format is simple. Take a real problem. Solve it first the easy, CPU-friendly way. Then bring in the GPU and deep learning — and keep an honest scorecard, wins and losses. A different problem each round; the same tension every time.

Here's what makes it a real fight. In grad school I spent days hand-optimizing a single GPU kernel — tiling, memory coalescing, the whole ritual. Coding agents now absorb that work: you reach for the GPU and harvest the benefit instead of grinding for it. But CPUs have decades of mature libraries and battle-tested habits behind them — so which corner actually wins on a given problem is genuinely up for grabs.

Round 1 takes on grading e-commerce search relevance on a laptop. It starts with the two approaches you'd reach for first — and the two traps that make "it agrees with our own labels" a dangerously misleading way to judge a relevance model.
